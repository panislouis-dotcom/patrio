Three Tabs
Tab 1 — Tabla
  • Composite score + sortable columns
  • Inline quality badges (⚠ / 🔴)
  • Click row → drawer slides in
  • Drawer has "Abrir detalle" → full page
  • Score weight controls (collapsible)
Tab 2 — Mapa
  • Leaflet + OpenStreetMap (free)
  • Pin color = composite score
  • Click pin → same drawer as table
  • Monterrey centered by default
  • Pins with quality issues get ⚠ icon
Tab 3 — Calidad
  • Summary: N issues across M prospects
  • Grouped by prospect, sorted by severity
  • Each issue: field + what's wrong + why
  • Click prospect → opens drawer
  • Red = error · Yellow = warning
Detail Page (full screen)
Accessible from drawer via "Abrir detalle →". Shows: Hero metrics bar (ROI, profit, cap rate, score) · Full cost breakdown (land, acquisition costs, permits, construction, total) · Map inset with exact pin · Timeline (investment date → sale date) · Quality section for this prospect specifically · Raw data table (all stored fields)
Quality Checks
🔴 Errors
latitude = 0 or longitude = 0
land_price = 0
sqm_land = 0
roi < 0 (pierde dinero)
sale_date ≤ investment_date
construction_overhead < 1.0
⚠ Warnings
construction_cost_per_sqm = 0
rent_monthly = 0
acquisition_cost_pct > 10%
investment_date already passed
profit < 500,000 MXN (worth it?)
